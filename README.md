## ✨ Features

### 🎨 Design
- Modern gradient-based aesthetic
- Floating blob animations
- Smooth scroll-triggered reveals
- Responsive typography with `clamp()`
- Interactive hover effects

### 📱 Responsive
- Mobile-first approach
- Hamburger navigation menu
- Adaptive grid layouts
- Optimized for all screen sizes

### 📄 Multi-Page
- **Homepage** (`index.html`) — Hero, services, edge, contact
- **Careers** (`careers.html`) — Open positions + CV submission
- SEO-optimized meta tags
- Open Graph tags for social sharing

### 🔗 Google Forms Integration
- Careers application → Google Form
- Enterprise request → Google Form
- All submissions → Google Sheets (automatic)
- CV uploads → Google Drive (automatic)
- No backend required

### 🔒 Security
- HTTPS (via Netlify)
- Security headers:
  - `X-Frame-Options: DENY`
  - `X-Content-Type-Options: nosniff`
  - `X-XSS-Protection: 1; mode=block`
  - `Referrer-Policy: strict-origin-when-cross-origin`
